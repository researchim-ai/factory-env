# ADR-008. Граница ядра и обучения

Статус: принято для v0.1.

Ядро принимает индекс операции или WAIT и возвращает снимок. Протокол агента — `reset` и `act(observation, mask)`. Цикл обучения живёт в `examples/` или в extra `rl`.

Библиотека не заставляет наследовать класс какого-либо RL-фреймворка.
