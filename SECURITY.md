# Безопасность

## Как сообщить

Используйте приватный отчёт GitHub Security Advisories этого репозитория. Не публикуйте сценарий, который читает или воспроизводит чужие производственные данные.

Поддерживаемая линия: текущий релиз 0.1.x.

## Модель угроз v0.1

- Сценарии — данные. JSON читается `json.loads`, YAML — `yaml.SafeLoader` с потолком узлов, глубины и размера файла. `eval`, `exec` и `pickle` для пользовательских файлов не используются.
- Размеры экземпляра и бюджеты событий/решений ограничены. Потолок поднимается только явным `ResourceLimits` или аргументом среды.
- Пакет не открывает сеть и не пишет в PLC, SCADA или OPC UA.
- В логи и отчёты бенчмарка не попадают переменные окружения и секреты. Не кладите их в `metadata` сценария.

## Чего библиотека не обещает

Симулятор не является защитным слоем для реального оборудования. Подключение к цеху, даже read-only, требует отдельной спецификации, изоляции сети и независимой оценки безопасности.
