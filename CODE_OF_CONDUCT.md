# Нормы общения

Участвуем в обсуждении кода, семантики и измерений. Не переходим на личности, не публикуем чужие данные и не выдаём непроверенный прогон за доказанный результат.

Неприемлемы оскорбления, домогательства и публикация частной переписки без согласия.

Если поведение мешает работе над проектом, напишите мейнтейнерам через приватный канал репозитория. Разбор не публикуется, пока это не нужно для защиты других участников.

Эти нормы относятся к issues, pull request, обсуждениям бенчмарков и примерам в репозитории.
