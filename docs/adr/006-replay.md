# ADR-006. Replay

Статус: принято для v0.1.

Трасса хранит версию пакета, версию схемы, алгоритм ГПСЧ, seed, хеш экземпляра, хеш конфигурации, действия, события и интервалы. Повтор сравнивает тип, приоритет, время (допуск `1e-9`), payload и производственные метрики.

Процессорное время в контракт равенства не входит. Совпадение бит float между разными платформами не обещается.
