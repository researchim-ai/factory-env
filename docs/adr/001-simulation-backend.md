# ADR-001. Движок симуляции

Статус: принято для v0.1.

Берём минимальную очередь на `heapq`, а не SimPy. Внешний API её не показывает. Замена движка допустима только если канонические тесты сохраняют порядок событий и метрики.

Причина: порядок `(time, priority, sequence)` и точки решения должны быть видны в коде, без скрытого календаря сторонней библиотеки.
