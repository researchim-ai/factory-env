# ADR-005. Награда и метрики

Статус: принято для v0.1.

Награда по умолчанию — `-delta_sim_time / time_scale`, включая последний переход. Альтернатива `terminal_makespan` платит только в конце. Ограничения маршрута и ёмкости не заменяются штрафом.

`failure_penalty` вычитается один раз при неуспехе. Метрики производства считаются по интервалам. Due date `null` не входит в суммы опоздания.
